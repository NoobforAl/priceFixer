How to test:
  1. Build the extension: npm run build (Chrome) or npm run build:firefox (Firefox)
  2. Load it in Chrome: go to chrome://extensions → Enable Developer Mode → Load unpacked → select the dist/ folder
  3. Load it in Firefox: go to about:debugging#/runtime/this-firefox → Load Temporary Add-on → select dist-firefox/manifest.json
  4. Open this page in the browser with the extension loaded
  5. Verify prices are highlighted or replaced according to the rounding rules
  6. Click "Add Price" to test MutationObserver on dynamic content
  7. Use the popup to toggle modes and per-site settings
